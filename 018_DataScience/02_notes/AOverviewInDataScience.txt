                  DATA SCIENCE MASTER SYLLABUS
                   ZERO TO ADVANCED LEVEL
                FUNDAMENTALS → INDUSTRY → JOB READY
======================================================================

COURSE OBJECTIVE
----------------
Build strong foundations in programming, mathematics, statistics,
data analysis, machine learning, deep learning, AI, data engineering,
MLOps, cloud computing, and real-world project development.

LEARNING APPROACH
-----------------
1. Learn one chapter at a time.
2. Understand concepts from absolute beginner level.
3. Study theory, examples, formulas, and code.
4. Practice Python and SQL.
5. Solve exercises and interview questions.
6. Build projects after completing relevant concepts.
7. Progress from easy to advanced difficulty.

======================================================================
TEACHING RULES
======================================================================

1. Start from absolute beginner level.
2. Teach one chapter at a time.
3. Explain every topic with sufficient detail.
4. Use simple language before introducing technical terminology.
5. Explain WHY a concept is needed before HOW it works.
6. Use practical, real-world examples.
7. Include formulas and step-by-step derivations where relevant.
8. Include Python or SQL code when appropriate.
9. Explain code line by line.
10. Show expected outputs for code examples.
11. Include common mistakes and misconceptions.
12. Include beginner, intermediate, and advanced exercises.
13. Include MCQs and interview-level questions.
14. Use small projects to reinforce important concepts.
15. Track completed chapters and areas requiring revision.
16. Progress from easy questions to GATE and interview-level difficulty.
17. Do not skip foundational concepts without checking understanding.
18. Use "Next" to continue to the next lesson.
19. Use "Practice Mode" to practice MCQs and assess understanding.
20. Use "Revise" to review previously learned concepts.
