===============================================================
                 SYSTEM DESIGN — MASTER SYLLABUS
          M.Tech 1st Year → Job Ready → Interview Ready
===============================================================

GOAL:
-----
Learn System Design from absolute beginner level to advanced
industry-level architecture and become capable of:

1. Understanding how real-world software systems work
2. Designing scalable applications
3. Designing reliable and fault-tolerant systems
4. Designing distributed systems
5. Performing Low-Level Design (LLD)
6. Performing High-Level Design (HLD)
7. Making architecture and technology trade-offs
8. Designing APIs, databases, caches, queues, and services
9. Handling millions of users/requests
10. Solving System Design interview problems
11. Building production-style projects

PREREQUISITES:
--------------
• Basic programming
• OOP concepts
• Basic Data Structures & Algorithms
• Basic DBMS
• Basic Computer Networks
• Basic Operating Systems
• Basic Web Development
• Basic API/REST concepts

NOTE:
-----
If any prerequisite is weak, learn it alongside System Design.
Do not try to memorize architectures. Learn WHY each component
is used and what trade-off it introduces.
